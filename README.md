# 插件墙 2.4.2

为 DeepSeek Harness 提供与工作区风格一致的插件墙：本地自动分组、搜索、拖动排序、弹窗管理和紧凑底部组件。无需 AI、API 密钥或额外服务。

## 安装

通过 DeepSeek Harness 自带的插件管理器安装 `local-sidebar-groups-2.4.2.tgz`。安装后按宿主提示重启。插件 bundle 自动禁用原生侧栏并注册替代侧栏，不需要执行额外安装脚本，也不需要修改宿主源码。

2.4.2 的 `engines.dsh` 只声明 DSH `0.2.2-rc.1` 与 `0.2.2-rc.2`。本版修复 rc.2 中工作区/会话列表无法渲染的问题，并在 macOS Desktop rc.2 真机验证。其他宿主版本和操作系统不作兼容承诺。

宿主或市场可读取版本声明检查兼容性。每次扩大范围前，先验证插件能激活、会话列表可见且能打开会话，以及卸载后原生侧栏可恢复。升级宿主后若会话列表消失，可完整卸载插件墙（包括 bundle）并重启，恢复原生侧栏。

如果曾手动写入过 `local-sidebar-groups.disabled: true` 的恢复覆盖，应移除这一旧覆盖后重新启用；全新安装没有此步骤。移除插件及其 bundle 登记后，宿主恢复原生侧栏。只单独禁用自定义侧栏条目不能恢复原生侧栏，因为 bundle 仍在禁用原生条目。

## 自动分组

首次安装和新插件入口出现时，根据可用的分类、标签、名称、描述与标识进行中英文关键词打分。宿主没有提供的字段会被跳过；仅靠标识或泛泛的描述不会强行猜测。

默认分组为「效率工具」「开发」「数据分析」「创作」「学习」「插件管理」「其他」。空组在侧栏隐藏，在管理弹窗中可见。插件可放入「不分组」区域，在插件墙顶部直接显示，不带文件夹标题。原常用插件自动迁移到顶部。

例如：编程教练、SQL 学习归学习；代码调试归开发；SQL 查询、决策工作台归数据分析；图像或写作归创作；定时任务、便利贴、工作流归效率工具。证据不足或得分相近则放到其他。教学用途比编程或 SQL 等领域词优先，显式分类信息比名称更有权重。

手动拖动后的归属始终优先，不会被自动分类覆盖。旧版保存的名称、顺序、归属和底部设置保留；升级时补充开发、数据分析、创作三个新默认组。之后删除的分类不会在每次启动时重新出现。修改元数据或语言可能更新尚未手动指定的自动归属。

## 操作

插件墙标题旁的搜索按钮筛选插件；调节按钮打开管理分组弹窗；加号用于新增分组。

侧栏和管理弹窗均支持拖动入口调整分组与顺序，弹窗还支持拖动分组标题排序、重命名和删除空组。「不分组」区域固定在管理弹窗顶部，可与普通分组互相拖动，不支持重命名；普通分组均可折叠。弹窗的更改点击保存后生效，取消放弃草稿；侧栏直接拖动立即保存。拖动时按 Escape 取消。

底部「状态与工具」默认收起用量卡片，移动访问显示为文字入口。旁边的设置按钮可控制显示、排序和默认展开方式；具体费用字段与账号在费用设置里调整。

头像与账号菜单固定在侧栏底部；上方插件入口、原生工作区和状态工具共用一个纵向滚动容器，按内容自然排列。工作区样式适配基于当前宿主，宿主升级后需复核。设置保存在当前客户端的 localStorage，不随安装包分发给其他用户。

## 旧本地版卸载后侧栏空白

早期通过手动配置启用的本地版本，可能在 desktop profile 的 `cordis.patch.yml` 留下 `ui-sidebar.disabled: true` 与 `local-sidebar-groups` 开关覆盖。插件管理器移除包和 bundle 时，这些手动覆盖可能仍保留，导致卸载后原生侧栏也不显示。

处理这类旧配置时，先私密备份 profile 补丁，再仅移除上述两个侧栏条目的手动开关覆盖，保留其他插件和用户配置。不要长期留下 `ui-sidebar.disabled: false` 作为修复，因为它也会覆盖将来重装时 bundle 对原生侧栏的禁用，造成两个侧栏争用槽位。清除旧覆盖后，由宿主默认配置与插件 bundle 分别管理卸载、安装状态。

该问题已在旧本地版的真实卸载场景确认并恢复；标准空白 profile 的 tgz 安装不依赖这些手动覆盖。
